# 🍄 皮克敏香菇計時器 (Pikmin Bloom Mushroom Timer)

專為《Pikmin Bloom 皮克敏》玩家打造的專屬 Chrome 擴充功能！
免開肥大地圖、零伺服器成本、隨點隨用，支援「**戰鬥打完倒數 + 自動 +5 分鐘重生冷卻提醒 + 網頁懸浮可拖曳香菇掛件**」，絕不錯過任何一場好菇！

---

## ✨ 核心特色

1. **隨處即用（Chrome Popup 輕量彈窗）**：
   - 不論在看 YouTube、刷網頁或寫程式，點擊右上角小香菇圖示，0.1 秒立即檢視所有戰鬥中的香菇。
2. **🌟 新增：網頁可拖曳懸浮香菇掛件（Floating Desktop Widget）**：
   - 點擊「📌 釘選」，香菇會直接長在網頁畫面上！
   - **自由拖曳**：可拖移到螢幕任意角落，自動記憶位置。
   - **Hover HUD 懸浮面板**：滑鼠移上去優雅展開剩餘秒數、進度條與快捷「提前打完」按鈕。
   - **Shadow DOM 隔離**：100% 免疫任何宿主網頁（YouTube, Facebook, GitHub 等）的 CSS 干擾。
3. **自動 +5 分鐘重生鬧鐘（搶菇神器）**：
   - 第一階段：戰鬥結束（跳通知提醒領取大水果與明信片）
   - 第二階段：自動無縫進入「5 分鐘冷卻倒數」，時間到再次推播通知進場搶新菇！
4. **支援 8 種香菇顏色標籤**：
   - 🔴 紅菇、🟡 黃菇、🔵 藍菇、⚪ 白菇、🟣 紫菇、🌸 粉羽菇、🪨 灰岩菇、✨ 特殊活動菇。
5. **雙模式快速設定**：
   - **倒數模式**：輸入剩餘時/分，附帶 `+15分`、`+30分`、`+1小時`、`+2小時`、`+4小時` 快捷按鈕。
   - **指定結束時刻**：直接挑選預計幾點幾分打完（如 `18:30`）。
6. **貼心功能：⚡ 提前打完**：
   - 戰鬥中若有強力路人/好友加入提早打完，點一下「提前打完」，立即無縫切換為 5 分鐘重生倒數！
7. **後台精準不漏接（`chrome.alarms` + 系統通知）**：
   - 關閉彈出視窗甚至把瀏覽器縮小，Service Worker 依然在背景精準計時，時間到右下角跳出系統橫幅通知。

## 🚀 本機安裝步驟（免上架、零成本自用）

1. 打開 Chrome 瀏覽器，在網址列輸入並前往：
   ```text
   chrome://extensions
   ```
2. 開啟右上角的「**開發人員模式 (Developer mode)**」。
3. 點擊左上角的「**載入未封裝項目 (Load unpacked)**」（如果已載入，點擊卡片上的「重新載入 🔄」圖示即可）。
4. 選擇本專案資料夾：
   ```text
   c:\Users\grape\source\repos\chrome-extension\pikmin-mashroom-extension
   ```
5. 安裝完成！建議點擊 Chrome 右上角的「拼圖圖示」，把「🍄 皮克敏香菇計時器」釘選到工具列上！
